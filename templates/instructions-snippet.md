## Skill routing

Before any multi-step, ambiguous or high-impact task, use the `skill-router` skill first: pick the installed skills, subagent and MCP tools for the task, announce them in one line (`Router → skills: … · agent: … · tools: …`), then invoke them. Skip this for quick questions and one-line edits. If I name a skill or tool, use that instead. Run `skill-audit` only when I ask for it.
